# En.Mostafa — Portfolio

موقع شخصي بالعربي والإنجليزي لطالب ثانوي وهاوي برمجة بيتعلّم HTML وCSS وJavaScript، ومهتم بالسايبر سكيورتي والذكاء الاصطناعي. يعرض مشروعًا واحدًا فقط: الموقع نفسه.

A bilingual portfolio for a secondary-school student and coding hobbyist learning HTML, CSS, and JavaScript, with an interest in cybersecurity and AI. The only featured project is this portfolio.

## Features / المميزات

- Arabic and English, with right-to-left and left-to-right layouts.
- Cinematic introduction and an interactive WebGL robot with greeting, replay, and pause controls.
- Responsive layout and reduced-motion support.
- Email link, email-copy button, and GitHub profile link.
- No external libraries, downloaded models, or build dependencies. A static robot illustration appears when WebGL is unavailable.

## Open locally / التشغيل المحلي

افتح `index.html` مباشرة في متصفح حديث. لا تحتاج إلى تثبيت أدوات أو مكتبات. استخدم JavaScript لعرض الروبوت وتبديل اللغة.

Open `index.html` in a modern browser. No installation or build step is required. JavaScript enables the robot, language switch, and interactive controls.

## Files / الملفات

| File | Purpose |
| --- | --- |
| `index.html` | Page structure, default Arabic content, and contact links |
| `styles.css` | Layout, colors, and responsive styles |
| `app.js` | Translations, language and motion settings, email-copy interaction |
| `robot.js` | Native WebGL scene and robot animation |
| `favicon.svg` | Site icon |

Language and motion settings are stored only in the visitor’s browser. The site does not automatically import repositories from GitHub. Contact uses an email link; there is no message database or contact form.
